04 · Sean Ellis PMF Test

The one benchmark we haven't earned yet, and we're saying so first.

Not Yet Measured

"How would you feel if you could no longer use this product?"

The standard test: survey real users, and if 40% or more say they'd be "very disappointed" to lose it, that's a strong product-market fit signal. We have not run this survey.

Running it today would measure enthusiasm for a hackathon demo, not for a product someone has actually depended on. The honest next step is a real pilot kitchen, a few weeks of real usage, then this exact survey. Until then, this line stays at zero rather than getting rounded up.

07 · Held Up Against Real Competitors, Not a Straw Man

Two adjacent categories exist. Neither does this job.

A quick note on terms before the comparison: ERP (Enterprise Resource Planning) is the big internal software system a large company runs its finances, supply chain, and operations on, think SAP. RFQ (Request for Quote) is a formal bidding event where a buyer asks several suppliers to compete for a contract. SAP Ariba, Coupa, and S/4HANA are specific ERP and e-procurement products that large enterprises already run. A mess kitchen has none of these, no ERP, no RFQ process, no existing system to plug into.

Enterprise Procurement AI (Pactum, Procol, PRMAI, Spendflo)
Genuinely autonomous and real, they negotiate with suppliers and execute purchase orders on their own. But they're built to sit on top of an ERP, they read and write supplier data through SAP Ariba, Coupa, or S/4HANA. A mess kitchen has none of that to plug into.
They're built around a formal RFQ, a negotiation event with multiple suppliers competing for a contract. A mess kitchen buying onions tomorrow has no negotiation, it's a spot-market retail purchase at a posted price. The mechanism these tools automate doesn't exist here.
Priced and justified against large contract value. A single onion order here is ₹96. The tooling isn't just oversized, the economics can't clear at this order size.
This System
Vendor score is 60% reliability, 40% price, the same weighted-scorecard methodology procurement literature treats as best practice, just sized for two inputs instead of the dozen an enterprise contract needs.
The LLM never computes the score. It's deterministic Python. The agent receives an already-ranked vendor list from a real tool call, it cannot misweight the formula or hallucinate a number, because it never calculates one.
The tiebreak (reliability first, then alphabetical) was tested against a manufactured exact-tie case, not just reasoned about on a whiteboard.
Proven under a condition scorecards rarely get shown live: the top-scored vendor ran out of stock mid-order, and the system fell through to the next vendor with no human input, in a real run, not a rehearsed one.

The mess/canteen software category (SpaceBasic, MealPe, RB Tech) all list "vendor management" as a feature, and it consistently means logging purchase orders and invoices, not deciding anything. The gap isn't "nobody's building software here." It's that record-keeping tools and enterprise negotiation tools both exist, and neither one makes a live decision when a vendor says no.

08 · The Honest Split

What's genuinely earned, and what's genuinely next.

What We're Proud Of
The deterministic / agentic split is a real architectural decision, not a buzzword, and it's demoed live, not claimed on a slide.
Two distinct failure modes recover on their own, in front of the jury, without a script pretending everything works the first time.
Every decision is traced and auditable. Nothing the agent does is a black box after the fact.
Built to run end to end, backend and frontend both working against a real database, not a local-only mockup.
What We're Still Building
A hard, agent-independent budget cap that the model cannot reason its way around.
An automated evaluation suite, so "the agent chose correctly" is a test result, not a manual check.
Real pilot usage with a kitchen, long enough to honestly run a PMF survey.
A security and multi-tenant review before a second kitchen ever touches this.
